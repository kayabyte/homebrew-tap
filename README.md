# Homebrew Tap for Kayabyte Native macOS Utilities

Official Homebrew Cask tap for [Kayabyte](https://kayabyte.dev/mac/) native Mac utilities. All applications are signed and notarized by Apple, operate 100% offline, and never upload personal documents to the cloud.

## Installation

Add this tap to your Homebrew installation:

```bash
brew tap kayabyte/tap
```

## Available Applications

| Application | Description | Install Command |
| :--- | :--- | :--- |
| **AlbumRescue** | Export and recover Apple Photos libraries & custom albums to plain folders | `brew install --cask albumrescue` |
| **NoteRescue** | Differential restore for Apple Notes, Contacts, Safari, and Calendars | `brew install --cask noterescue` |
| **Pairfold** | Non-destructive folder sync & mirror backup with safety archive retention | `brew install --cask pairfold` |
| **Exhibitly** | Convert iMessage & WhatsApp chat threads into court-ready numbered PDFs | `brew install --cask exhibitly` |
| **Balanced** | Offline PDF bank statement to CSV/QBO converter with math verification | `brew install --cask balanced` |
| **Gridhand** | Merge, split, compare, and clean massive Excel & CSV files without freezing | `brew install --cask gridhand` |
| **Upsharp** | Local AI image upscaler and photo enhancer accelerated on Apple Silicon | `brew install --cask upsharp` |

Or install directly in one step without tapping first:

```bash
brew install --cask kayabyte/tap/<app-name>
```
